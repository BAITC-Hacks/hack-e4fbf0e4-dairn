# Комментарии по документации ветки `codex/work`

Документы прочитаны на состоянии ветки, содержащем автономный `ekt-catalog-service`, API,
контейнеризацию и ограниченный AI-поиск. Ниже — не описание реализованных фактов EKT, а
фиксированные ограничения, которые важно сохранить при развитии сервиса.

## Что уже определено

- Сервис умеет работать с сохранённым образцом первой страницы каталога и явно маркирует
  такой источник как частичный.
- Product не подменяет отсутствие цены, валюты или наличия выдуманными значениями.
- CLI, HTTP API и Docker-проверки документированы отдельно от live-проверки EKT.
- AI-поиск ограничивает данные, передаваемые модели, и возвращает только кандидатов без
  подтверждения совместимости.

## Комментарии к данным товара

- Для большинства исследованных карточек заполненные характеристики являются основным
  источником структурированных параметров.
- У части товаров характеристики пусты, а сведения расположены только в описании. Описание
  нужно получать и передавать отдельным полем; оно не становится структурированной
  характеристикой без проверяемого правила извлечения.
- Фильтр EKT «В наличии» не показывает численный остаток. До появления подтверждённого
  поля API нельзя вычислять или подставлять количество, включая `0`.
- Для detail-ответов нужно сохранить raw JSON, HTTP status, время получения и правила
  заполнения полей для карточек с обоими вариантами наполнения.

## Что остаётся непроверенным

1. Авторизованные запросы к EKT, детали товаров, пагинация за первой страницей и реальные
   ошибки upstream.
2. Валюта, количество и семантика остатков, склады, сертификаты и структурные различия
   между list и detail.
3. Правила технической совместимости и актуальное наличие, необходимые для настоящего
   подбора аналогов.
4. Production-развёртывание: домен, HTTPS, live credentials, реальный smoke-test и
   стратегия rollback.

## Практическое правило

Нормализованный контракт должен различать «известно», «отсутствует» и «не проверено».
Пустой результат выборки, пустой раздел характеристик или фильтр «В наличии» не являются
доказательством отсутствия товара, параметров или численного остатка.
